What this spike tests

  • 3-band EQ approximation: Strudel has no true 3-band EQ. This spike approximates it honestly: LOW cut → .hpf() (up to ~400 Hz at −1); HI cut → .lpf() (down to ~700 Hz at −1); MID is a UI placeholder — the knob exists for the real-mixer feel but is currently a no-op pending a credible Strudel approximation (e.g. band-reject via stacked lpf + hpf would require two chained calls and may colour the sound unpredictably). Every branch remains balanced regardless.
  • Filter sweep: negative → LP sweep from open down to ~200 Hz; positive → HP sweep from ~200 Hz up to ~3.2 kHz. Both sides are monotonic so the knob tracks intuitively.
  • Smooth BASS SWAP: 6 steps × 160 ms — the hero control. Ramps deck A LOW from its current value to −1 (bass gone) while simultaneously ramping deck B LOW from −1 to 0 (bass present). Updates on-screen knobs each step. Guards against overlap.
  • Hold-to-fire FX paddles: STUTTER (.ply("4")), GATE (.struct("1 0 1 0 1 0 1 0")), and ECHO-OUT (.delay(0.4).delaytime(0.1875).delayfeedback(0.6).room(0.3)) live on the master stack and drop in/out on mousedown/mouseup with no lingering timer.
  • Whether the compose order — LOW → MID → HI → FILTER → gain — keeps every branch paren/quote-balanced across all EQ combinations.
