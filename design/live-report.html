Five ways the Live page could feel

The brief: the Live floor — where the DJ cuts a track turn-by-turn — works, but it reads like a generic dark-neon webpage with no point of view. Each spike below re-skins the exact same Live page (the rig · the console · the roll · the live code) against one specific, sourced taste — a real design lineage, not a vibe. Same track (NEON MELT · drill · 140 BPM · F minor) in every one, so you're comparing skins, not content. Click Open to audition each full-screen.

Read before judging: there's no browser in the build environment, so these are code-verified but un-rendered — your eyes are the gate, exactly like the menu and remix rounds. Two are light-ground (OP-Lab, Riso Rave) and one is near-white (Grid): stunning in a browser showcase, but a full reskin would need to reconcile with the dark menu/nav — a whole-shell decision, not just Live.

The five sourced tastes

01

OP-Lab

Teenage Engineering (OP-1 / OP-Z) · Dieter Rams / Braun

A precise toy you want to touch. Swedish industrial minimalism: restraint is the flex — cream faceplate, engraved micro-labels, one hot accent, real drawn hardware.

  • One accent, zero gradients — orange only on the live/critical element
  • Drawn hardware — machined crossfader slot, SVG encoders with tick indicators, 3D rubber keys
  • Dot-matrix screens for the roll + code, engraved uppercase labels under every control

RISK Warm paper palette is a full-shell commitment — jarring beside the current dark menu/nav until the whole app follows.

02

Riso Rave

The Designers Republic · Warp Records · WipEout · rave-flyer riso

The loud, cultural one. Sheffield electronica print crossed with photocopied warehouse flyers: it should look screen-printed, not rendered.

  • Overprint physics — two riso spot colours in multiply self-mix into a third
  • Misregistration ghost on every headline — the definitive TDR tell, pure CSS
  • HUD chevron crossfader, halftone pianoroll, hazard stripes + warning micro-copy

RISK Highest wow-factor, but a pale flyer ground is loud against code and unreadable in a dark room — would need a dark variant to ever ship live.

03

Serato

Serato DJ Pro · Ableton Live · Pioneer Rekordbox

The credible-instrument one. The dense, calm workstation real DJs stare at for hours — and Acetate genuinely is a DJ tool, so the authenticity lands.

  • Scrolling waveform + beatgrid as the hero timing element (frequency-coloured)
  • Deck A cyan / Deck B amber — Serato's two-deck convention; VU meters, pro rotary EQ
  • Channel-strip parts, tabular BPM/key readouts, IDE-feel code pane

RISK Closest to the current dark theme, so the smallest leap — but it borrows an existing look, so it's the weakest unique signature for a portfolio piece.

04

Tape Console

Cassette-futurism · Studer tape · Roland & Moog · Nostromo used-future

The warm, tactile one. 1970s–80s studio hardware you'd find in a real room — used-future warmth, not sci-fi neon.

  • Walnut end-cheeks + brushed-aluminium faceplate, warm vignette, silk-screened labels
  • Real SVG VU needle meters, illuminated push-buttons, tape-reel platters
  • Backlit amber / seven-seg readouts, coloured patch-cable accents

RISK Skeuomorphism is a knife-edge — done a hair too far it reads kitsch/dated, and the visual weight competes with code legibility.

05

Grid

Swiss International Typographic · Müller-Brockmann · Vignelli · Bauhaus

The anti-neon. Grid, type and whitespace do all the work — the strongest possible "a real designer decided this" signal.

  • One red, one black, paper white — no gradient, glow, shadow or rounded corner anywhere
  • Visible modular grid + baseline rules, a huge track index number, religious alignment
  • Controls as minimal diagrams — slider = line + dot, record = concentric rings (Deck B in red)

RISK Bravest and most tasteful, but Swiss calm can read clinical/quiet — it may drain the live-performance energy a DJ floor wants.

My read

For a portfolio showcase whose story is "AI + craft + a point of view", the two most memorable — the ones that instantly read as human-designed — are Riso Rave (maximum distinctive impact, unmistakably not-generic) and OP-Lab (the refined, tasteful counter-argument). Audition those two first.

If you'd rather it read as a serious instrument than an art object, Serato is the safe, credible pick and the smallest leap from today. And Grid is the dark-horse — the highest pure-taste ceiling, if you're brave enough to make a live tool quiet.

My one-line call: Riso Rave for the wow, OP-Lab if you want it to age well.
